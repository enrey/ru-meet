# Транскрипт по миксу, исходные дорожки только для уточнения

Статус: принято. Заменяет раздел «Предлагается: раздельная транскрибация» из [ADR 0005](0005-transcribe-microphone-and-system-separately.md). Хранение трёх потоков в `audio.mp4` по ADR 0005 остаётся.

## Контекст

Обработка после записи распознавала микрофон и системный звук как два отдельных транскрипта и сводила их строки по времени. На записи через колонки (22.11) это дало:

- дубли: эхо собеседника из колонок распознавалось на микрофоне вторым экземпляром его фраз;
- параллельные абзацы и сбитый порядок: реплики обоих источников шли вперемешку длинными строками;
- строки без спикера: диаризация пропускает строки микрофона, а эхо склеивало ваши фразы с чужими в одну строку.

Подавить эхо на уровне сигнала не удалось. Вычитание одной задержанной копии не срабатывает в реальной комнате: корреляция 0,37–0,49, а системная дорожка после громкости вывода на −29 дБ. Удаление эха по совпадающим словам убирало дубли, но оставляло обрывки и всё равно ломало вид транскрипта.

## Решение

- Основной транскрипт всегда строится по потоку 0 (микс): Silero с порогом 2 с → GigaAM → одна упорядоченная лента. Спикеров определяет диаризация по миксу, как для записей без дорожек.
- Исходные дорожки строк не создают. Они нужны только для уточнения сомнительного слова — слова, в котором смешаны кириллица и латиница. Окно вокруг такого слова GigaAM Multilingual распознаёт по очереди: сначала дорожка, где в этот момент звучит голос, затем вторая дорожка, затем микс. Принимается первый вариант, который однозначно совпадает с соседними словами строки, и меняется только само слово.
- Где «звучит голос», определяется по громкости в окне относительно обычного уровня речи этой же дорожки (90-й перцентиль RMS по 100 мс). Абсолютные уровни не сравниваются: системная дорожка записывается после громкости вывода.
- Дорожки декодируются, только если в транскрипте нашлось хотя бы одно смешанное слово.
- Сигнальное подавление эха (`suppress_echo`) удалено: для микса оно не нужно.

## Последствия

Перебивания распознаются по миксу как один голос, и слова того, кого перебили, могут пропасть. Это осознанная цена: восстанавливать их из дорожек значило бы снова вставлять в транскрипт строки или слова второго источника. Наложение голосов сомнительным местом не считается.

Записи без исходных дорожек и импортированные файлы работают как раньше: всё по миксу.
