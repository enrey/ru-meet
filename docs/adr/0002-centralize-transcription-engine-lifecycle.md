# Централизация движков транскрипции за единым seam

Whisper, Parakeet и GigaAM имеют разные правила выбора модели, инициализации, повторного использования и выгрузки, которые сейчас дублируются в записи, импорте и ретранскрипции через прямой доступ к глобальным экземплярам движков.

Модуль `audio::transcription` будет единственным владельцем выбора провайдера и жизненного цикла движка: callers получают готовый движок через его единый interface, а конкретные adapters и их глобальное состояние остаются скрытой implementation; это сохраняет различия провайдеров локальными и не позволяет workflow координировать acquire/reuse/unload самостоятельно.
