## Убрать перепаковку старых записей (не раньше апреля 2027)

С 0.9.0 склейка записи пишет индекс MP4 в начало файла (`-movflags +faststart`). Записи, сделанные раньше, держат индекс в конце, и WebKit на macOS не воспроизводит их через asset-протокол. Поэтому `get_meeting_audio_path` (`frontend/src-tauri/src/audio/recording_commands.rs`) один раз перепаковывает такой файл через `edge_trim::ensure_faststart`.

Примерно через полгода после выпуска 0.9.0 (16.10.2026) старые записи либо уже открывались и перепакованы, либо не нужны. Тогда удалить вызов, `ensure_faststart` и `index_trails_audio` вместе с тестом.
