# Раздельная транскрибация и исправление терминов после записи

Статус — постановка к реализации. Формат записи с дорожками микрофона и системного звука описан в [ADR 0005](../adr/0005-transcribe-microphone-and-system-separately.md).

## Одна настройка

В блоке настроек **«Транскрибация»** добавить одну галку **«Раздельная транскрибация и исправление терминов после записи»**. Она управляет обеими операциями. По умолчанию галка включена у новых пользователей и в существующих профилях без этой настройки. Явно сохранённое значение действует и после перезапуска.

При включённой галке после остановки записи выполняется одно задание. Основной GigaAM v3-e2e-ctc распознаёт речь каждого доступного источника один раз. GigaAM Multilingual 220M уточняет только подозрительные короткие участки. Итоговый текст собирается до запуска саммаризации. При выключенной галке действует прежняя обработка по смеси без автоматической коррекции терминов. Ручная команда «Транскрибировать заново» с выбранным GigaAM v3 использует ту же настройку и тот же конвейер. Переключение галки само по себе не запускает обработку архива.

## Источники звука после записи

По контракту ADR 0005 в `audio.mp4` со штатными исходными дорожками поток 0 — смесь для воспроизведения, поток 1 — микрофон, поток 2 — системный звук. Источник определяется по порядку потоков в записи ru-meet. Произвольные потоки импортированного файла нельзя автоматически считать микрофоном и системным звуком.

| Запись | Основной проход GigaAM v3 | Дополнительный проход GigaAM Multilingual 220M |
|---|---|---|
| Запись ru-meet с исходными дорожками | Распознать микс (поток 0) одной лентой, как запись без дорожек; спикеров определяет диаризация. Дорожки строк не создают ([ADR 0008](../adr/0008-transcript-from-mix-tracks-for-refinement.md)). | Окно вокруг подозрительного слова распознать по очереди: дорожка, где в этот момент звучит голос, затем вторая дорожка, затем микс. Принять первый вариант, однозначно совпавший с соседними словами. |
| Старая встреча или импорт без известных исходных дорожек | Распознать микс один раз. | Взять короткое окно из того же микса. |

При включённом живом тексте во время звонка виден черновик. После остановки фоновое задание строит итоговый транскрипт из сохранённой записи. При выключенном живом тексте это первое распознавание встречи. Итоговый транскрипт — одна упорядоченная лента по миксу со временем относительно начала записи; спикеров определяет диаризация. При одновременной речи микс распознаётся как один голос, и слова перебитого могут пропасть — это принятая цена ([ADR 0008](../adr/0008-transcript-from-mix-tracks-for-refinement.md)). Эхо колонок в транскрипт не дублируется, потому что дорожки строк не создают.

## Как исправляется искажённый термин

1. В результате GigaAM v3 найти непрерывную последовательность букв, внутри которой смешаны кириллица и латиница. Пробел и дефис разделяют последовательности. Читаемые «Конфлюенс», «докер», «работаем в Docker» и «IT-команда» сохраняются.
2. Однозначную подмену исправить локально. В контрольном примере `сoрри` латинская `o` (U+006F) заменяется кириллической `о` (U+043E). Массовая транслитерация смешанных названий может испортить корректное написание.
3. Для оставшегося искажения взять по меткам GigaAM v3 короткий аудиофрагмент с окружающими словами **с той же дорожки, на которой оно обнаружено**. Для микрофона с эхоподавлением использовать сигнал после той же обработки и на той же временной шкале, что и в основном проходе. Несколько близких подозрительных слов одной реплики можно проверить одним вызовом. При недоступности нужной исходной дорожки оставить исходный текст участка. Ветка с миксом применяется к записям без известных исходных дорожек.
4. Локально распознать фрагмент второй моделью **GigaAM Multilingual 220M**, вариант ASR `ctc` с посимвольным декодером из `ai-sage/GigaAM-Multilingual`. При интеграции закрепить ревизию весов и совместимый формат для локального движка. [Карточка модели](https://huggingface.co/ai-sage/GigaAM-Multilingual)
5. Совместить варианты по окружающим словам в том же порядке. При сравнении допустимо игнорировать регистр и пунктуацию. При однозначных границах заменить только искажённый участок. Он может состоять из нескольких токенов, например `коnflinc tito G`. За его границами сохранить исходные слова и пунктуацию. Сохранить связь правки с исходным текстом, временем, дорожкой и спикером. Обновить текстовые смещения при изменении числа слов.
6. При неясных границах, отсутствии меток, пустом ответе или сохранившемся искажении оставить исходный участок. Если вторая модель недоступна, завершить раздельное распознавание и применить доступные однозначные буквенные исправления. В настройках показать доступность модели и действие для установки.

## Критерии приёмки

- Новая установка и обновление профиля получают одну включённую галку. Выключение сохраняется после перезапуска. Проверены оба режима живого текста и ручное повторное распознавание.
- Для трёхпоточной и однопоточной записи основной STT распознаёт микс один раз; транскрипт идёт одной лентой в порядке времени без дублей, в том числе через колонки. Дорожки читаются, только если нашлось смешанное слово.
- Для трёхпоточной записи проверить искажения отдельно на микрофоне и в системном звуке, в том числе при перебивании. GigaAM Multilingual 220M получает короткое окно только с дорожки соответствующей реплики. Для встречи с одним миксом проверить, что оба прохода используют микс. При потере доступа к исходной дорожке исходный текст соответствующего участка сохраняется.
- Для `сoрри` получается «сорри» без вызова второй модели. Читаемые термины сохраняются. На фрагментах с `конфlеn`, `коnflinc` и `миting` проверить, удаётся ли GigaAM Multilingual 220M восстановить «Конфлюенс» и «митинг». При достоверном выравнивании исправляется только термин; слова вокруг, источник и авторство реплики сохраняются. Проверить также случай, когда вторая модель пропустила соседние слова.
- Экран встречи, экспорт и саммари получают один сохранённый результат. Повтор прерванного задания не создаёт дубликаты и не затирает ручные правки.
