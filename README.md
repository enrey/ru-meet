## Что такое Ru-Meet

Ru-Meet — специализированное настольное приложение для записи и расшифровки **русскоязычных встреч**. Оно оптимизировано для русской речи и использует локальные модели распознавания, включая **GigaAM v3**, а также Whisper и Parakeet.

Запись, распознавание речи, определение голосовой активности, диаризация, хранение истории и встроенная ИИ-суммаризация могут выполняться непосредственно на компьютере пользователя. После загрузки выбранных моделей для основной работы приложению не требуется интернет.

Ru-Meet подходит для совещаний, интервью, исследований, юридических консультаций и любых разговоров, которые нельзя передавать сторонним сервисам.

## Главное

### 👥 Диаризация — автоматическое разделение по спикерам

Ru-Meet определяет, **кто и когда говорил**, размечает реплики участников и сохраняет временную шкалу спикеров вместе с расшифровкой.

- полностью локальная обработка аудио;
- движки **Pyannote + WeSpeaker** и **NVIDIA Sortformer v2**;
- автоматическое назначение спикеров после записи или импорта;
- повторный запуск диаризации для готовой встречи;
- ручное переименование участников с обновлением всех связанных реплик.

### 🇷🇺 Распознавание русской речи

- **GigaAM v3** — специализированная модель для русского языка;
- **Whisper** — универсальное многоязычное распознавание;
- **Parakeet** — быстрое локальное распознавание на современных процессорах;
- **Silero VAD** — локальное определение участков с речью и отсечение тишины;
- выбор модели и режима обработки под конкретное оборудование.

### 🔒 Полностью приватный режим

- аудиозаписи, транскрипты, заметки и модели хранятся локально;
- распознавание и диаризация не требуют облачного API;
- встроенная локальная языковая модель создаёт итоги без передачи текста наружу;
- база встреч остаётся на устройстве пользователя;
- поддерживается переносимый режим хранения данных;
- нет обязательной регистрации, подписки или внешнего сервера.

> **Важно:** полностью локальный режим не передаёт содержимое встреч третьим лицам. Если пользователь самостоятельно выбирает Claude, Groq, OpenRouter либо другой внешний OpenAI-совместимый сервис для создания итогов, текст отправляется выбранному провайдеру по его правилам. Для максимальной приватности используйте встроенную модель или локальный Ollama.

### 🎙️ Запись встреч

- одновременный захват микрофона и системного звука;
- интеллектуальное смешивание аудиопотоков;
- защита от клиппинга и автоматическая обработка уровней;
- транскрибация во время встречи;
- продолжение записи при временном отключении одного из устройств;
- системные уведомления о состоянии записи и обработки.

### 📁 Импорт и повторная обработка

- импорт существующих аудиозаписей;
- расшифровка локальными моделями;
- повторная транскрибация с другой моделью;
- диаризация ранее записанных встреч;
- сохранение расшифровки, заметок и метаданных в локальной базе.

### ✨ ИИ-итоги и заметки

- локальная генерация краткого содержания встречи;
- выделение решений, тезисов и дальнейших действий;
- редактируемые структурированные заметки;
- собственные OpenAI-совместимые endpoints;
- опциональная интеграция с Ollama, Claude, Groq и OpenRouter.

## Как обеспечивается приватность

В локальном режиме данные проходят только через компоненты на вашем компьютере:

```text
Микрофон и системный звук
          ↓
      Silero VAD
          ↓
GigaAM / Whisper / Parakeet
          ↓
 Локальная диаризация спикеров
          ↓
Локальная база и локальный ИИ-итог
```

Ru-Meet не требует загрузки записей на сервер для распознавания. Подключение к интернету используется для первоначальной загрузки выбранных моделей, проверки обновлений и только тех внешних ИИ-провайдеров, которые пользователь включил явно.

## Установка

### Windows

1. Откройте страницу [последнего релиза](https://github.com/enrey/ru-meet/releases/latest).
2. Скачайте установщик для Windows.
3. Запустите установку и следуйте инструкциям.

Для оптимальной производительности рекомендуется современный x64-процессор с AVX2. Доступность аппаратного ускорения зависит от выбранной сборки и установленного оборудования.

### macOS

Если готовый пакет доступен в [релизах](https://github.com/enrey/ru-meet/releases), скачайте его и перенесите Ru-Meet в папку «Программы». Инструкции по самостоятельной сборке находятся в [docs/BUILDING.md](docs/BUILDING.md).

### Linux

Используйте готовый пакет из [релизов](https://github.com/enrey/ru-meet/releases) либо соберите приложение по [инструкции для Linux](docs/building_in_linux.md).

## Сборка из исходников

Потребуются Rust, Node.js и pnpm. Дополнительные системные зависимости перечислены в [руководстве по сборке](docs/BUILDING.md).

```bash
git clone https://github.com/enrey/ru-meet.git
cd ru-meet/frontend
pnpm install --frozen-lockfile
pnpm tauri:dev
```

Основные команды:

| Команда | Назначение |
| --- | --- |
| `pnpm tauri:dev` | Запуск приложения в режиме разработки |
| `pnpm tauri:build` | Обычная production-сборка |
| `pnpm tauri:dev:cuda` | Разработка с CUDA для NVIDIA |
| `pnpm tauri:dev:vulkan` | Разработка с Vulkan |
| `pnpm tauri:dev:openblas` | Разработка с OpenBLAS |
| `pnpm tauri:dev:metal` | Разработка с Metal на macOS |

Подробнее об ускорении: [GPU_ACCELERATION.md](docs/GPU_ACCELERATION.md).

## Технологии

- **Tauri 2** и **Rust** — нативная часть приложения;
- **Next.js** и **React** — пользовательский интерфейс;
- **GigaAM v3**, **Whisper** и **Parakeet** — распознавание речи;
- **Pyannote + WeSpeaker** и **NVIDIA Sortformer v2** — диаризация;
- **Silero VAD** — определение голосовой активности;
- **ONNX Runtime**, DirectML, CUDA, Vulkan, Metal и CoreML — выполнение моделей и аппаратное ускорение;
- **SQLite** — локальное хранение встреч, расшифровок и настроек.

Описание устройства проекта: [архитектура Ru-Meet](docs/architecture.md).
